# slide-ocr

Локальное desktop-приложение: пачка фотографий слайдов → связный Markdown лекции.

Распознавание идёт через OpenAI-compatible REST (LM Studio, llama.cpp `llama-server`, DeepSeek и другие). OCR-движок в программу не встроен.

## Возможности

- Список изображений с превью, сортировка (реверс, имя, дата) и перестановка строк
- Промпт собирается из опций (языки, таблицы, стили, обрывки, иллюстрации) и правится вручную
- Иллюстрации вырезаются локально по tool-вызовам модели и кладутся рядом с Markdown
- Тихий дедуп одинаковых кадров (PDQ) и склейка overlapping-текста
- Вывод: сплошной текст, разделитель `-----`, или отдельные файлы

## Сборка

Нужен Go 1.25+ и зависимости Fyne (C-компилятор, заголовки X11/Wayland на Linux).

```sh
make build
make test
make lint
```

Запуск: `make run`. Перед распознаванием поднимите локальный сервер, например LM Studio на `http://127.0.0.1:1234/v1`.

## Интерфейс

Три вкладки: **Вход** (файлы, размер, статус, порядок), **Распознавание** (бэкенд, папка сохранения, Пуск), **Вывод** (фрагменты или сплошной текст, Сохранить).

Прогресс-бар общий, внизу окна. Текст каждого слайда появляется на «Выводе» сразу после OCR. «Сохранить» пишет уже готовые фрагменты в выбранную папку и не останавливает распознавание.

- Сплошной текст и режим с `-----` → `{папка}/recognized-text.md`
- Отдельные файлы → `{папка}/{имя-слайда}.md` (коллизии: `-2`, `-3`, …)

Загрузка файлов и папок — только на вкладке **Вход** (и перетаскиванием на окно). ПКМ по строке открывает крупный просмотр; зажатый ПКМ с движением по списку показывает карточку превью справа сверху.

Последняя колонка списка — галочка участия (по умолчанию включена). Снятая галочка исключает файл из OCR и убирает его текст с «Вывода». **Пауза** останавливает пакет; **Пуск** продолжает с неготовых слайдов и подхватывает текущие настройки модели. На «Выводе»: **Очистить вывод** (с предупреждением о несохранённом) и **Распознать заново** у фрагмента.
