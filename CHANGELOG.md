# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Added

- Desktop GUI на Fyne с тремя вкладками: вход (пакет картинок, сортировка и перестановка), распознавание через OpenAI-compatible VLM, вывод Markdown.
- Локальный tool `crop_region` / `save_slide_image` для вырезания иллюстраций в sidecar-файлы.
- Тихий дедуп одинаковых кадров (PDQ) и склейка overlapping-текста соседних слайдов.
- Потоковый вывод фрагментов по мере OCR, общий прогресс снизу окна, сохранение в выбранную папку не останавливает распознавание.
- Навигация Вход↔Вывод по галочке статуса и имени файла, крупное превью слайда по ПКМ.
- Пауза пакетного OCR с продолжением с неготовых слайдов; галочка участия в списке; «Очистить вывод» с предупреждением о несохранённом; «Распознать заново» для одного фрагмента.
- Превью по зажатому ПКМ в правом верхнем углу окна.

### Changed

- Папку сохранения выбирают на вкладке «Распознавание»; «Сохранить» пишет туда `recognized-text.md` или файлы по именам слайдов.
- Вкладка «Вывод» по умолчанию показывает таблицу фрагментов; переключатель возвращает сплошной текст.
- Кнопка «Стоп» переименована в «Пауза»; Пуск не пересчитывает уже готовые слайды.
