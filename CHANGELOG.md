# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Added

- Профили провайдера на вкладке «Распознавание»: несколько URL и моделей, действующий профиль отмечен галочкой и раскрыт, остальные свёрнуты. Профиль можно добавить; удаление (если профилей больше одного) спрашивает подтверждение.
- Desktop GUI на Fyne с тремя вкладками: вход (пакет картинок, сортировка и перестановка), распознавание через OpenAI-compatible VLM, вывод Markdown.
- Локальный tool `crop_region` / `save_slide_image` для вырезания иллюстраций в sidecar-файлы.
- Тихий дедуп одинаковых кадров (PDQ) и склейка overlapping-текста соседних слайдов.
- Потоковый вывод фрагментов по мере OCR, общий прогресс снизу окна, сохранение в выбранную папку не останавливает распознавание.
- Навигация Вход↔Вывод по галочке статуса и имени файла, крупное превью слайда по ПКМ.
- Пауза пакетного OCR с продолжением с неготовых слайдов; галочка участия в списке; «Очистить вывод» с предупреждением о несохранённом; «Распознать заново» для одного фрагмента.
- Превью по зажатому ПКМ в правом верхнем углу окна.
- Жёлтый статус «Нет текста», если OCR не нашёл букв; слайд остаётся в списке и на «Выводе» с пустым текстом; опция вставить такой слайд целиком как иллюстрацию.
- Время распознавания файла в таблице «Вход»; под прогресс-баром — прошедшее время пакета и прогноз окончания.
- Стрелки порядка на вкладке «Вывод» — тот же список файлов, что на «Входе».
- На вкладке «Вывод» кнопка «Экспорт» и строка команды. По умолчанию pandoc собирает PDF; `%s` — базовое имя файла без расширения. Для отдельных файлов команда запускается по очереди из папки сохранения.

### Changed

- Папку сохранения выбирают на вкладке «Вывод»; «Сохранить» пишет туда `recognized-text.md` или файлы по именам слайдов.
- Вкладка «Вывод» по умолчанию показывает таблицу фрагментов; переключатель возвращает сплошной текст.
- Кнопка «Стоп» переименована в «Пауза»; Пуск не пересчитывает уже готовые слайды.
- Порядок OCR, фрагментов и склейки Markdown следует текущему списку на «Входе»; смена сортировки во время пакета берёт следующий неготовый сверху.
- Карточка превью по зажатому ПКМ увеличена примерно на 20%.
